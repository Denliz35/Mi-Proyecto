# Mi-Proyecto

# 🌴  Palmaar Eventos- Salón de Fiestas

Salon de fiestas ubicado en Zona Sur de Buenos Aires, Ranelagh. 
Cuenta con capacidad para mas de 100 personas y brinda diferentes servicios.
Realiza fiestas infantiles, casamientos,cumpleaños,15 años,comuniones,batismos,etc.

---

## 🚀 Demo / Sitio Web
Puedes ver la página en vivo aquí:https://denliz35.github.io/Mi-Proyecto/

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica de la web.
* **CSS3:** Estilos personalizados, Flexbox/Grid y animaciones.
* **Font Awesome / Google Fonts:** Iconografía y tipografías.
* **Git & GitHub:** Control de versiones y deployment con GitHub Pages.

---

## 📌 Características Principales

* Diseño 100% *responsive* (adaptable a celulares y computadoras).
* Sección de servicios/productos interactiva con efectos `:hover`.
* Galería de imágenes y reseñas de clientes.
* Formulario de contacto.
